# Robot Elliot V8.2 — подготовка к нескольким инструментам

Этот релиз не включает дополнительные платные анализы. Активен только XAUUSD.

## Что изменено

- единый `config/instruments.json` с одним активным инструментом;
- `ROBOT_INSTRUMENT` может переопределить символ для будущего отдельного процесса;
- ключевые MT5, Risk Manager, Executor, FULL и Scout используют единый выбранный символ;
- состояния будущих инструментов изолируются в `state/<SYMBOL>/`;
- XAUUSD сохраняет прежние пути и полностью совместим с существующим сервером;
- список `future_candidates` является только планом и никогда сам не запускает Claude;
- политика FULL/Scout, FVG, структурного стопа и запрета Claude при позиции не изменена.

## Важное ограничение

V8.2 запускает один инструмент одним процессом. Для включения новой пары нужен
отдельный контролируемый релиз, тестирование у брокера и решение по стоимости.
